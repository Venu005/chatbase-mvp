# Languages and how the AI answers

- **Answers stay grounded**: the assistant uses only your sources and Q&A answers. When it doesn't know, it says so and
  suggests contacting the business, or talking to a person.
- **Customers' own language**: it replies in the language and script the customer writes in, including Hinglish in
  English letters. Voice works in English, Hindi and 9 other Indian languages.
- **Follow-up questions** such as "and the price?" work, because the previous question is used in the search too.
- **Small talk** ("thanks!", "dhanyavaad") is answered without searching, and doesn't count as a knowledge gap.
- **Formatted answers**: bold, lists and links in the website chat and the inbox; WhatsApp formatting on WhatsApp; short
  spoken sentences in voice.

Which AI models the platform uses is set by whoever runs it: see [AI providers](../providers.md) and
[AI in production](../ai-in-production.md).
