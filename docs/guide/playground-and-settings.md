# Playground and settings

**Where:** Agent → **Playground** and Agent → **Settings**

## Settings

- **Instructions**: tone, business details, what to do when the answer isn't known (for example "share our WhatsApp
  number +91…"), languages to support.
- **Welcome message** and **brand colour** for the chat window.
- **Talking to a person**: turn handoff on or off, the message customers see when they ask for a person, and e-mail
  alerts. See [inbox and handoff](inbox-and-handoff.md).
- **Collect leads**: see [leads](leads.md).

## Playground

- A private test chat. It never hands off to a person, and it doesn't count in Analytics.
- Only the agent's owner, signed in to the dashboard, can use it.
- Each answer uses one message credit, like a real chat. Use **Start a new chat** to test follow-up questions from
  scratch.
